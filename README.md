# Super Trader Bot (v3) — заменяет предыдущего бота полностью

Полностью переработанный автономный торговый бот для Bybit / Binance (через CCXT),
15-минутный таймфрейм + фильтр старшего ТФ (1h).

Главный файл намеренно называется `inflow_scanner_v2_render.py` — так же, как у
бота-предшественника, чтобы не пришлось менять команду запуска в деплое
(Render / Procfile / systemd и т.п.). Просто замените все файлы старого бота
файлами из этого архива.

## Что нового в v3

Исходная версия содержала критический баг: анализировала ЕЩЁ ФОРМИРУЮЩУЮСЯ свечу
каждые 60 секунд, из-за чего сигналы могли сработать на случайном внутрисвечном
фитиле ("покупка на хае"). Плюс: кэш старшего таймфрейма замораживался навсегда,
не было персистентных риск-контуров, размер позиции считался по хрупкой проверке
имени символа, не проверялось реальное выставление стоп-лосса на бирже.

Всё это исправлено, и добавлен двухфазный вход:

1. **FIRE** — TTM Squeeze + голосование (тренд/свечи/паттерны) + анти-чейз фильтры
   (RSI, дистанция от EMA в ATR) находят сетап, но **не открывают сделку сразу**.
2. **PULLBACK CONFIRM** — бот ждёт до `PULLBACK_MAX_BARS` баров, пока цена
   откатится к EMA50 и закроется обратно в сторону сделки с объёмом. Только
   тогда — реальный вход. Если цена сломала структуру squeeze-зоны — сетап
   инвалидируется без входа.

## Возможности

- Анализ тренда (EMA 50 / 200), TTM Squeeze (Bollinger внутри Keltner), треугольники,
  свечные паттерны (молот, падающая звезда, поглощение)
- Двухфазный вход: FIRE -> ожидание отката -> CONFIRM (не покупаем хай, не входим против тренда)
- Анти-чейз фильтры: RSI-диапазон, ATR-экстеншн от EMA
- Фильтр старшего таймфрейма (1h), обновляется по TTL, не замораживается
- Фильтр объёма и ATR, персистентный кулдаун на символ
- Риск-менеджмент: 1% риска на сделку, RR >= 1:2, кап на размер позиции,
  MAX_POSITIONS, дневной лимит убытка, блокировка после серии убытков подряд
- Сопровождение позиции: безубыток, ATR-трейлинг, частичное закрытие, тайм-стоп,
  выход по затуханию моментума
- Проверка реального выставления SL на бирже после входа (иначе — закрытие для безопасности)
- Персистентное состояние (JSON) — переживает рестарт процесса
- Режим DRY_RUN (без реальных ордеров), опциональные Telegram-алерты
- Логирование сигналов и сделок в CSV

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

```bash
export BYBIT_API_KEY="твой_ключ"
export BYBIT_API_SECRET="твой_секрет"
# опционально
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
```

В `config.py` (или через ENV):
- `DRY_RUN=true` — безопасный режим (по умолчанию)
- `DRY_RUN=false` — реальная торговля (осторожно!)
- `ENTRY_MODE=pullback` — рекомендуемый режим (вход на откате)
- `ENTRY_MODE=breakout` — legacy режим (вход сразу на пробое, не рекомендуется)
- `SYMBOLS="BTC/USDT,ETH/USDT,SOL/USDT"` — список торгуемых пар

## Запуск

```bash
python inflow_scanner_v2_render.py
```

## Структура

- `inflow_scanner_v2_render.py` — главный цикл (имя сохранено для совместимости с деплоем)
- `config.py` — все настройки (ENV-переопределяемые)
- `storage.py` — персистентное состояние (позиции, кулдауны, риск-контуры, armed-сетапы)
- `indicators.py` — TTM Squeeze, EMA, RSI, ATR, Bollinger, Keltner, момент-гистограмма
- `data_manager.py` — данные через CCXT (только закрытые бары!)
- `analyzer.py` — анализ паттернов и индикаторов
- `strategy.py` — двухфазное принятие решений (FIRE -> PULLBACK CONFIRM)
- `execution_manager.py` — исполнение ордеров, риск-контуры, сопровождение позиций
